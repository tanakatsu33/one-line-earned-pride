An entry for make.fun's **"One Line of Earned Pride"** bounty ($5 USDC).

## Entry

> After three years relearning to write with his left hand, Mr. Alvarez signed his granddaughter's birthday card — and this time the ink didn't shake.

## How it works

`main.ts` is a small Node/TypeScript program (using only `node:fs` and `node:path`) that validates the entry (1–240 characters, not only whitespace) and writes it to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, defaulting to `/output`).

```sh
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
